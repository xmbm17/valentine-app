# 💝 Valentine's Day React App

A sweet and interactive Valentine's Day app that combines:
- An interactive "Will you be my Valentine?" question with a playful "No" button that runs away
- A customizable card creator where you can add their name and a personal message
- A beautiful animated reveal with floating hearts

## Features

1. **The Question** - Try to click "No" and see what happens! 😏
2. **Customize** - Add their name and a heartfelt message
3. **Beautiful Reveal** - An animated Valentine's card with floating hearts

## Setup Instructions

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Start the development server**:
   ```bash
   npm start
   ```

3. **Open your browser**:
   The app will automatically open at `http://localhost:3000`

## How It Works

- The "No" button moves away whenever you try to hover over it
- The "Yes" button takes you to customize your Valentine's card
- Enter their name and an optional message
- See the beautiful animated reveal with floating hearts!

## Technologies Used

- React 18
- CSS3 Animations
